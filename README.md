# Sharpies Group Project

## Project Ideas List

- Meal Planner app
- Calendar app
- List app
- Note Keeper

## Project Summary List

- Meal Planner: A meal planning app that creates a list of needed groceries for the planned meals
- Calendar: A calendar app that includes goal setting integration
- List: A list app that is setup so you can make and save different lists under different categories
- Notes: A note keeping app that you can also highlight things typed in, add images to, and free hand draw in
